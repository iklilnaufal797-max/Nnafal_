# Rekening Bank

```Sistem Rekening bank``` Sederhana di program java

## Fitur

- Transfer saldo
- Tampilan saldo awal
- Tampilan saldo setelah transaksi
- Info Jumlah Rekening bank yang tersedia

## Cara Menjalankan Program

langkah langkah menjalankan program:

```bash
  Javac RekeningBank.java MainBank.java
  Java MainBank
```
